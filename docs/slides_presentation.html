CÀI ĐẶT & TRIỂN KHAI PLAYWRIGHT TEST

Quy trình từ chuẩn bị môi trường, cấu hình test runner, viết kịch bản giả lập người dùng đến tự động quay video kết quả kiểm thử.

1. Cài Đặt

Node.js LTS, npm install & trình duyệt Chromium tự động.

2. Triển Khai

Cấu hình tự bật web, ghi hình HD và viết kịch bản test.

3. Thực Thi

Lệnh CLI, chế độ UI và file chạy 1-Click tự động.

Bước 1 / 4

Cài Đặt Môi Trường & Thư Viện Playwright

1. Chuẩn bị Node.js

Cài đặt Node.js LTS (bản ổn định) từ nodejs.org để có sẵn runtime và trình quản lý gói npm.

node -v
npm -v

2. Cài đặt thư viện vào thư mục test

Di chuyển vào thư mục e2e-tests và tải gói @playwright/test:

cd e2e-tests
npm install

3. Tải trình duyệt kiểm thử độc lập

Playwright sử dụng phiên bản Chromium riêng biệt để đảm bảo môi trường test sạch, không phụ thuộc vào trình duyệt cá nhân: 

npx playwright install chromium
💡 Ưu điểm: Chỉ cần chạy 1 lần duy nhất, sau đó bất kỳ máy tính nào cũng có thể chạy test mượt mà.

Cấu Hình Tự Khởi Động Web & Quay Video HD

e2e-tests/playwright.config.js Config Cốt Lõi 
module.exports = defineConfig({
  testDir: './tests',
  workers: 1, // Chạy tuần tự rõ ràng
  use: {
    baseURL: 'http://localhost:8088',
    video: {
      mode: 'on', // Luôn ghi hình mọi test
      size: { width: 1280, height: 720 },
    },
    launchOptions: {
      slowMo: 400, // Nhịp độ vừa phải
    },
  },
  webServer: {
    command: 'python -m http.server 8088 ...',
    port: 8088,
    reuseExistingServer: true, // Tự kết nối
  },
});

🎥 Tự Động Ghi Hình (video: 'on')

Không cần bật OBS hay phần mềm quay ngoài, Playwright tự xuất file .webm độ phân giải 720p lưu vào videos/.

⏱️ Nhịp độ quan sát (slowMo: 400ms)

Thêm khoảng chờ giữa các thao tác để khi trình chiếu, người xem nhìn rõ từng cú click chuột và ô nhập liệu.

🌐 Tự chạy Web (webServer)

Nếu quên bật server trước, Playwright tự động bật web ngầm tại cổng 8088, không bao giờ bị lỗi mất kết nối.

Cấu Trúc 1 File Code Test Gồm Những Gì?

1. Định Vị (Locators)

Tìm nút, ô nhập theo ID hoặc text:

page.locator('#menuSearch')
page.locator('text=Bạc xỉu')
page.locator('#btnOpenCheckout')
2. Thao Tác (Actions)

Mô phỏng hành vi người dùng:

await searchInput.fill('Bạc xỉu');
await drinkCard.click();
await discount.selectOption('VIP');
3. Xác Thực (Assertions)

Khẳng định kết quả đúng như kỳ vọng:

await expect(item).toBeVisible();
await expect(btn).toBeEnabled();
await expect(bill).not.toHaveText('0');

👉 Quy tắc vàng: Cứ sau một hành động (như thêm món, đổi mã giảm giá, ấn thanh toán), ta gọi một hàm expect(...) để đảm bảo hệ thống phản hồi đúng giao diện và dữ liệu.

Bước 4 / 4

Các Lệnh Thực Thi & Xem Báo Cáo Kết Quả

1. Chạy có mở trình duyệt (Headed Mode)

Trình duyệt Chrome tự bật lên để theo dõi trực tiếp:

npx playwright test --headed

2. Chạy giao diện tương tác (UI Mode)

Bảng điều khiển trực quan, xem timeline từng giây:

npx playwright test --ui

3. Xem báo cáo HTML (Report)

Mở trang kết quả Xanh/Đỏ có tích hợp video xem ngay:

npx playwright show-report

⚡ Tiện Ích Chạy 1-Click (Không Cần Gõ Lệnh)

Nhóm đã đóng gói sẵn các file thực thi tự động ở thư mục gốc:

  • 👉 run-e2e-tests.bat : Tự chạy toàn bộ test & mở report
  • 👉 quay-video-bandicam.bat : Tự bật Bandicam & chạy live
